# よけろ！たいやきくん

Unityで開発している個人制作の2D回避アクションゲームです。

2025年度の大学祭では「YOKERO（仮）」を、2026年度の大学祭ではキャラクターやビジュアル素材を更新した「よけろ！たいやきくん」を展示しました。両年度とも体験者にアンケートを実施し、その結果を参考にしながらゲームの改善を進めています。

## ゲーム概要

海の中を泳ぐたい焼きのキャラクター「たいやきくん」をマウスで操作し、次々に現れる敵を避けながら、できるだけ長く生き残ることを目指すゲームです。

時間経過とともに敵の出現頻度や移動速度が変化するため、状況に応じた判断と回避操作が求められます。

また、ゲーム本編だけでなく、タイトル画面にもクリック操作によるインタラクションや隠し演出を取り入れ、プレイ開始前から遊び心を感じられるゲームを目指しています。

### 世界観・雰囲気

舞台は、魚や海藻が存在する水中世界です。主人公のたいやきくんは、黄金色の体と大きな目が特徴の、親しみやすいデフォルメキャラクターです。

青を基調とした水中背景に、色鮮やかな海藻や魚影、泡、水中に差し込む光などを組み合わせ、海の中の雰囲気を表現しています。タイトル画面では、海藻や魚影、泡、水中光にアニメーションを加え、動きのある水中空間を演出しています。

こうしたビジュアルや演出を通じて、2000年代のキッズ向けメダルゲームを思わせる、レトロでポップな雰囲気を目指しています。

### 現在の基本仕様

- マウス操作によるプレイヤー移動
- 敵との接触によるゲームオーバー
- 通常敵と大型敵の出現
- 時間経過に応じた難易度の変化
- 生存時間の計測（最大180秒）
- 上位5件の生存時間ランキング
- タイトル、ゲーム、リザルトの各シーン
- タイトル画面の背景アニメーションや隠し演出

### 技術的な特徴

- マウスの高速移動時に、移動経路上の敵との衝突を検出する仕組み
- 移動方向の推定と平滑化による、キャラクターの滑らかな方向転換
- Unity Test Frameworkを使用した、衝突判定やプレイヤー操作、タイトル画面のインタラクションなどの自動テスト

## 操作方法

- **マウス移動：** たいやきくんを移動
- **スタートボタン：** ゲーム開始
- **リトライボタン：** ゲーム終了後に再挑戦
- **タイトルへ戻るボタン：** リザルト画面からタイトル画面へ戻る

プレイヤーはゲーム画面内を移動し、敵との接触を避け続けます。

## プロジェクトの起動方法

1. リポジトリをクローンする。
2. Unity Hubでプロジェクトのルートフォルダを追加する。
3. `ProjectSettings/ProjectVersion.txt`に記載されたUnity Editorを使用する。
4. `Assets/Scenes/TitleScene.unity`を開く。
5. Unity EditorのPlayボタンから実行する。

## テスト

Unity Test Frameworkを使用し、Edit ModeとPlay Modeの自動テストを実装しています。

テストコードは`Assets/Tests/`に配置しています。テストの実行方法や対象については[開発環境・セットアップ](docs/DEVELOPMENT.md)を参照してください。
